Any project can open a claim campaign. Only Agent ID holders will be able to claim — that is the whole point. Creating a campaign is free (you only pay the network gas fee).

How it works

Agent ID is the on-chain identity of an Agentic Wallet on BNB Chain (a non-transferable name.ai NFT, contract 0x60b9…022f). AgentGate reads balanceOf(your address) on that contract directly on-chain: if it is above zero, your wallet is a verified Agent ID holder and can claim. No sign-ups, no lists, no servers — the gate is the chain itself.

Safety: AgentGate never holds, moves, or asks approval for your assets. Claims and check-ins are free (network gas only), and the contract has no owner or admin who could change the rules after deployment. Contract: view on BscScan.

AgentGate is an informational tool built for the Binance Wallet × BNB Chain Agent ID Hackathon. It does not promise or imply any returns.
